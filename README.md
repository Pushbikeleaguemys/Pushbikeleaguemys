# CorePushBike League 2026

Single-file league app: pole-position standings, race results, rider profiles and scoring rules.

- Open `index.html` in a browser (or host it with GitHub Pages: Settings > Pages > Deploy from branch `main` / root).
- **Marketplace** tab: anyone can post items for sale (up to 3 photos, brand, price, location). Customer listings are saved on their own device; items posted while logged in as admin are published to everyone.
- **Admin login** (top right) unlocks editing of riders, results and photos, and sync from the CorePushbike Excel tracker (.xlsx).
- Edits are stored in the browser only. Use Admin > "Download updated app (.html)" and commit the new file as `index.html` to publish changes.

Note: the admin login is a client-side gate, not real security. Do not rely on it to protect confidential data.
